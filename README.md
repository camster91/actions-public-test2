# actions-public-test2

A small public-repository GitHub Actions probe. Its only workflow is a manually dispatched job that prints a fixed message.

## Run the probe

When GitHub Actions is enabled for this repository, open **Actions**, choose **Probe**, and select **Run workflow**. The job does not check out source, read secrets, write repository contents, or deploy anything.

This is a disposable diagnostic repository, not an application or package. It has no releases or supported software versions.
